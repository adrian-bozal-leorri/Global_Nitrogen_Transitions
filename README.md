# Global_Nitrogen_Transitions
R code and data supporting the study "Divergent nitrogen transition pathways during global agricultural development", examining global patterns of agricultural nitrogen use, cropland N surplus, protein supply, and economic development across 130 countries from 1992 to 2022.

This repository contains the data and R code supporting the manuscript:

**Divergent nitrogen transition pathways during global agricultural development**

The study examines changes in agricultural nitrogen (N) use, cropland N surplus, protein supply, and economic development across 130 countries from 1992 to 2022.

## Data

The `data/` directory contains the country-level dataset used in the analyses:

`Data_Final_31.csv`

The dataset covers 130 countries over the period 1992–2022 and integrates indicators of economic development, agricultural N use, cropland N surplus, agricultural land use, greenhouse gas emissions, and protein supply.

Further information on the original data sources and variable definitions is provided in the manuscript and its Supplementary Information.

## R scripts

The analyses are organized according to the main figures and analytical components of the manuscript.

- `01_Figure1_GAM_relationships.R`  
  Fits the generalized additive models (GAMs) used to characterize nonlinear relationships among economic development, agricultural N inputs, protein supply, and cropland N surplus. The script also performs model diagnostics, derivative analyses, and sensitivity analyses.

- `02_Figure2_global_trajectories.R`  
  Generates the global country trajectories used to visualize changes in N surplus per unit protein supply, N input intensity, and protein supply.

- `03_Transition_classification.R`  
  Classifies country-level changes between 1992 and 2022 into nitrogen transition outcomes, including absolute and relative decoupling, and evaluates sensitivity to the classification threshold.

- `04_Figure3_trajectory_configurations.R`  
  Characterizes recurrent multivariate trajectory configurations using country-level trajectory features, principal component analysis (PCA), and k-means clustering, including sensitivity analyses to alternative scaling methods.

- `05_Figure4_absolute_decoupling_development_context.R`  
  Examines the economic-development context and cropland N-surplus trajectories associated with absolute decoupling.

- `99_Print_all_results_for_manuscript.R`  
  Collects the principal numerical outputs generated by scripts 01–05 into a single report for result verification. This script does not refit models or recalculate classifications.

## Running the analyses

The repository should be used with its root directory set as the R working directory.

Scripts use relative paths and expect the input dataset at:

```text
data/Data_Final_31.csv
```

Analyses should be run in numerical order:

```text
01 → 02 → 03 → 04 → 05
```

Script `03_Transition_classification.R` must be run before scripts `04` and `05`, because these analyses use the country-level transition classification generated by script 03.

The scripts automatically create the required `results/` and `plots/` directories when executed.

Script `99_Print_all_results_for_manuscript.R` can be run after scripts 01–05 to compile the principal numerical results.

## Software

All analyses were conducted in R.

Required R packages are checked at the beginning of each script. If any required package is missing, the corresponding script will report which package needs to be installed.

Random seeds are set within analyses involving stochastic procedures to ensure reproducibility.
